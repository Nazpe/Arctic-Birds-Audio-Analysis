BlueOasis Technical Assessment by Nuno Pedrosa

For this acessment, I used the Arctic Bird Sounds dataset, present in https://osf.io/b9trx/overview. Please save it on the main folder of the repo, with the name DataS1.

A web based data visialuzation tool is present in the Technical Assessment, in the folder Data visualization tool, please open the index.html file in the web to view and explore (currently adreesing 3 audio samples).


The main code and conclusions are present on the notebook main.ipynb. The pyproject.toml specifies the required Python version and declares the project’s dependencies, while the uv.lock file records the exact versions of all resolved dependencies.
